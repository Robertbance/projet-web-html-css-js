# Roberto Digital Hub 🌐

## Description
**Roberto Digital Hub** est un site web personnel développé par **Robert Bancé**, étudiant en Modélisation, Simulation et Calculs Scientifiques à l’Université Virtuelle du Burkina Faso.  
Il est conçu comme une **plateforme de partage de ressources numériques** :  
- Articles (guides, outils bureautiques, design, développement web, etc.)  
- Projets pratiques (maquettes Figma, analyse de données avec Python, etc.)  
- Formulaire de contact pour échanges directs  

Le site se veut **pédagogique, simple et accessible**, afin d’aider aussi bien les **débutants** que les **professionnels** dans l’apprentissage du numérique.

---

##  Fonctionnalités
- Page d’accueil avec présentation de l’auteur.  
- Section **À propos** : présentation du projet et du parcours académique.  
- Section **Articles** : ressources téléchargeables (PDF, guides).  
- Section **Projets** : démonstrations de maquettes et notebooks.  
- Section **Contact** : formulaire validé par JavaScript (nom, email, message).  
- Interaction dynamique :  
  - Validation du formulaire avec message de confirmation.  
  - Bouton « **Changer de thème** » (clair / sombre).  
  - Bouton « **Retour en haut** » visible au défilement.  

---

##  Technologies utilisées
- **HTML5** : structure du site.  
- **CSS3** : mise en forme et responsive design.  
- **JavaScript** : interactions dynamiques et validation des formulaires.
